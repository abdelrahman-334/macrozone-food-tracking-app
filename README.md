# MacroZone

MacroZone is a mobile calorie-counting app built with Expo and React Native. It uses an AI API to interpret food entries and provide quick calorie estimates, helping users log meals without manually looking up every ingredient.

## What it does

- Accepts meal and food descriptions from the user
- Uses AI to estimate the calories in an entry
- Makes it easier to keep a running record of daily food intake

The goal is to make calorie tracking feel quick and practical for everyday meals.

## Tech stack

- Expo
- React Native
- Expo Router
- AI-powered nutrition analysis API

## Getting started

### Prerequisites

- Expo Go on a physical device, or an Android emulator / iOS simulator
